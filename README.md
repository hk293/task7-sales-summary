# Task 7 – Basic Sales Summary with SQLite and Python

This task connects to an SQLite database (`sales_data.db`) using Python, runs an SQL query to get total quantity and revenue per product, and displays the results as a printed table and a bar chart.

## Files

- `task7.py`: Creates the database and adds sample data
- `task7_chart.py`: Runs SQL query, shows summary, and plots a chart
- `sales_data.db`: The SQLite database
- `sales_chart.png`: The generated bar chart image

## Tools Used

- Python (sqlite3, pandas, matplotlib)
- SQLite (built into Python)
